# REST API — прогноз загрузки трамвайных маршрутов

Базовый путь: `/api/v1`. Ответы — JSON (UTF-8, camelCase). Даты — `YYYY-MM-DD`, месяцы — `YYYY-MM`.
Swagger UI: `/swagger-ui.html`, OpenAPI: `/v3/api-docs`. Health: `/actuator/health`, метрики: `/actuator/prometheus`.

## Ошибки

Все ошибки — `application/problem+json` (RFC 9457) с понятным сообщением на русском:

```json
{"title":"Некорректный запрос","status":400,
 "detail":"Параметр from: дата 2025-10-01 вне горизонта day (2025-11-01 … 2025-12-31)",
 "instance":"/api/v1/forecast","parameter":"from"}
```

Коды: 400 — неверные параметры (в т. ч. неизвестная остановка), 404 — нет маршрута в пути `/routes/{route}/stops`
или несуществующий путь, 405 — метод не поддерживается, 413 — слишком большая выгрузка, 415 — неверный формат
тела, 500 — внутренняя ошибка (без стектрейса). Исключение — синтаксически некорректный URL
(неэкранированный `|`, битое `%ZZ`, запрос длиннее лимита): его отклоняет HTTP-сервер (Netty) до приложения, с
кодом 400/414 и пустым телом. Спецсимволы в параметрах нужно URL-кодировать (`|` → `%7C`).

Повторяющиеся `routes`/`stops` объединяются: `routes=1&routes=7` ≡ `routes=1,7`. Номера маршрутов, часов,
месяцев — целые числа; дробные отклоняются с 400.

## Горизонты

| `horizon` | Период | Данные | Гранулярность по умолчанию |
|---|---|---|---|
| `day` | 2025-11-01 … 2025-12-31 | почасовой прогноз модели (краткосрочный) | `hour` |
| `month` | 2025-11-01 … 2025-12-31 | тот же прогноз, агрегаты по дням/месяцам с интервалом (среднесрочный) | `day` |
| `year` | 2026-01-01 … 2026-12-31 | сценарный дневной прогноз 2026 (долгосрочный); часы — профиль суток по типу дня | `month` |
| `history` | 2025-01-01 … 2025-10-31 | факт (успешные валидации) — для сравнения | `day` |

## GET /api/v1/stops

Все остановки: `[{"stopId":"2594","route":1,"direction":0,"seq":1,"name":"Чертаново Южное","lat":55.59468,"lon":37.590884,"weight":0.042276}]`.
`weight` — доля посадок маршрута на остановке (сумма по маршруту = 1).

## GET /api/v1/routes/{route}/stops

`{"route":1,"directions":[{"direction":0,"stops":[{...как выше}]},{"direction":1,"stops":[...]}]}`. 404 — нет маршрута.

## GET /api/v1/forecast

Прогноз с агрегацией. Параметры (все необязательны):

| Параметр | Пример | Смысл |
|---|---|---|
| `horizon` | `day` | `day` \| `month` \| `year` \| `history` |
| `routes` | `7,50` | маршруты (по умолчанию все 10) |
| `stops` | `2594,2595` | только эти остановки (сумма их долей внутри маршрута); без `routes` — все маршруты, обслуживающие остановку, с `routes` — только указанные |
| `segment` | `1:0:3-10` | участок: `маршрут:направление:seqFrom-seqTo` (включительно); если заданы `routes`, маршрут участка должен в них входить |
| `from`, `to` | `2025-11-10` | интервал дат (по умолчанию весь горизонт) |
| `hourFrom`, `hourTo` | `7`, `9` | интервал часов 0–23 включительно: `7`–`9` = 07:00–10:00 (по умолчанию 0–23) |
| `granularity` | `hour` | `hour` \| `day` \| `month` \| `total` |
| `split` | `route` | `route` — ряд на маршрут; `none` — один суммарный ряд `all` |

Точек в ответе (корзин × рядов) не больше 60 000, иначе 400 «Слишком детальный запрос» — укрупните
гранулярность, сократите интервал или используйте `/api/v1/export`.

Корректирующие коэффициенты (сценарий «что, если», не применяются к `history`); множители (`monthMult`,
`routeMult`, `dowMult`, множитель события) — от 0 до 10, `precip` — от 0 до 300 мм, `beta` — от −1 до 1:

| Параметр | Пример | Смысл |
|---|---|---|
| `precip` | `2025-12-05:15,2025-12-06:3` | осадки дня, мм: `k = exp(β·(ln(1+мм) − n_m))`, `n_m` — средний ln(1+мм) по дням месяца m в 2025 (`meta.weather.monthNormLog1p`) |
| `beta` | `-0.012` | чувствительность к осадкам (по умолчанию −0.012) |
| `monthMult` | `12:1.03` | множитель месяца (сезон) |
| `routeMult` | `17:0.95,7:1.1` | множитель маршрута |
| `dowMult` | `6:0.9,7:0.9` | множитель дня недели (1 = Пн … 7 = Вс) |
| `event` | `7%7C50:2025-12-20:2025-12-21:0.5:10-17` | событие: `маршруты:начало:конец:множитель[:часы]`, маршруты через `\|` (в URL — `%7C`) или `*` = все; часы включительно: `10-17` = 10:00–18:00, или список `8\|9\|17`. Параметр можно повторять |

Ответ:

```json
{
  "query": {"horizon":"day","from":"2025-11-10","to":"2025-11-10","hourFrom":0,"hourTo":23,
            "granularity":"hour","split":"route","routes":[7],"stops":[],"segment":null,"scenario":true},
  "unit": "посадки",
  "series": [{"key":"7","label":"Маршрут 7","color":"#3cb44b",
              "points":[{"t":"2025-11-10T08:00","base":2410.0,"pred":2386.1,"lo":null,"hi":null}]}],
  "totals": {"base": 21000.0, "pred": 20500.3, "delta": -499.7, "deltaPct": -2.38},
  "byRoute": [{"route":7,"base":21000.0,"pred":20500.3,"delta":-499.7,"deltaPct":-2.38}],
  "notes": ["..."],
  "computeMs": 0.41
}
```

- `t`: `2025-11-10T08:00` (hour), `2025-11-10` (day), `2025-11` (month), `total`.
- `base` — прогноз модели, `pred` — с корректирующими коэффициентами (без сценария `pred == base`).
- `lo`/`hi` — интервал «80 % ошибок меньше» (бэктест: месяц маршрута ±14.1 %, сумма маршрутов ±11.3 %). Он
  измерен только для месяца целиком, поэтому отдаётся для корзины «полный месяц» (`granularity=month`) или
  «итог» за ≥ 28 дней, по всем часам (0–23), на уровне маршрута/сети. Для часов, дней, неполных месяцев и
  остановок интервал не измерен — `null`.
- Для `history` `base == pred == факт`.

## GET /api/v1/map

Данные карты на один день: почасовые значения по маршрутам и остановкам (анимация по часам — на клиенте).

Параметры: `date` (обязательно, 2025-01-01 … 2026-12-31: до 31.10.2025 — факт, 1.11–31.12.2025 — прогноз,
2026 — сценарий года), `routes`, и те же коэффициенты сценария, что у `/forecast`.

```json
{
  "date": "2025-11-10", "mode": "forecast", "dayType": {"code": 0, "label": "рабочий"},
  "weather": {"precipMm": 1.2, "tempC": 3.4},
  "routes": [{"route":7,"name":"...","color":"#3cb44b","hourly":[0,0,12,...24 чисел],"total":21000.0,
              "lines":[{"direction":0,"coords":[[37.59,55.59],[37.58,55.60]]}]}],
  "stops": [{"stopId":"2594","route":1,"direction":0,"seq":1,"name":"...","lat":55.59,"lon":37.59,
             "weight":0.042,"hourly":[...24],"total":840.2}],
  "maxStopHour": 190.4
}
```

`mode`: `history` | `forecast` | `year`. Маршруты без геометрии присутствуют в `routes` с пустым `lines`.

## GET /api/v1/map/live

Живой факт для карты: принятые (`/ingest`) посадки по маршрутам и часам на дату и алерты детектора (порог по
умолчанию). Не кэшируется; клиент опрашивает раз в несколько секунд и раскладывает факт маршрута по остановкам
долями из `/map`.

```json
{"date":"2025-11-10","available":true,"lastHour":14,"receivedTotal":131826,
 "routes":[{"route":7,"hourly":[0,0,0,0,0,21,480,...24]}],
 "alerts":[{"route":7,"fromHour":9,"toHour":12,"kind":"drop","deviationPct":-61.0,"message":"..."}]}
```

`available=false`, `lastHour=null` — за дату ничего не принято.

## GET /api/v1/export

Те же параметры, что у `/forecast`, плюс `format=csv|xlsx` (по умолчанию `csv`) и `level=route|stop`.
`level=stop` — строка на каждую остановку (только маршруты с остановками). Лимит — 1 000 000 строк (иначе 413).
Колонки: `horizon, route, direction, seq, stop_id, stop_name, period, base, pred, lo, hi` (`direction`/`seq` — для
`level=stop`; для участка выгружаются ровно его остановки выбранного направления). CSV — разделитель `;`, UTF-8 с BOM
(открывается в Excel). Имя файла: `forecast_<horizon>_<from>_<to>.<ext>`.

## GET /api/v1/fleet

Где усиливать выпуск (прогноз посадок на вагон выше нормы маршрута) и где его можно сократить (резерв, экономия).
Параметры: `routes`, `from`, `to`.

```json
{"summary":[{"route":1,"normBpv":119.3,"fleetMax":25,"serviceHours":1257,"candHours":315,
             "extraVehicleHours":528,"feasibleVehicleHours":528,"topHours":"14:00, 13:00, 12:00","candShare":0.251,
             "reserveHours":202,"reserveVehicleHours":444,"reserveTopHours":"21:00, 22:00, 20:00",
             "plannedVehicleHours":12774,"reserveShare":0.04}],
 "candidates":[{"route":1,"date":"2025-11-01","hour":13,"pred":1344,"nPlan":11.0,"bpv":122.2,"norm":119.3,"extra":1,"extraFeasible":1}],
 "reserve":[{"route":50,"date":"2025-12-01","hour":20,"pred":947,"nPlan":17.0,"bpv":55.7,"norm":125.2,"need":11,"reserve":5}],
 "method":"...","reserveMethod":"..."}
```

- **Усиление** (`candidates`): прогноз посадок на вагон > норма; `extra = ceil(прогноз / норма) − выпуск`.
- **Резерв** (`reserve`): часы 7:00–22:59, где прогноз посадок на вагон < 50 % нормы. Оставляем
  `need = max(ceil(прогноз / (0.7 · норма)), 2)` вагонов, снимаем не больше 30 % планового выпуска часа. Не
  оцениваются дни не в обычном режиме маршрута и вечер 31.12 (бесплатный проезд).

## GET /api/v1/quality

Качество модели и область применимости: `{"leaderboardWapeScore":0.9125,"byHorizon":[...],"byLevel":[...],"byRoute":[...],"folds":[{"fold":"A: ≤31.01 → фев–мар","score":0.913}]}`.

## GET /api/v1/summary

Сводка диспетчера на день. Параметры: `date` (обязательно, 2025-01-01 … 2026-12-31) и те же коэффициенты сценария,
что у `/forecast`.

```json
{"date":"2025-11-10","mode":"forecast","dayType":{"code":0,"label":"рабочий"},"weather":{"precipMm":0.0,"tempC":3.2},
 "network":{"total":245771.0,"peakHour":8,"peakValue":23613.0,"hourly":[...24],
            "weekAgoDate":"2025-10-27","weekAgoTotal":242871.0,"deltaWeekPct":1.2},
 "routes":[{"route":17,"name":"...","color":"#008080","total":54649.0,"peakHour":8,"peakValue":5293.0,"hourly":[...24],
            "weekAgoTotal":...,"deltaWeekPct":...,"extraVehicleHours":13,
            "reinforceHours":[{"hour":8,"pred":5293.0,"nPlan":27.0,"norm":174.1,"extra":6}],
            "reserveVehicleHours":11,
            "reserveHours":[{"hour":21,"pred":1457.0,"nPlan":22.5,"norm":174.1,"need":12,"reserve":6}]}],
 "hotStops":[{"stopId":"osm535844761","route":17,"direction":0,"seq":5,"name":"Метро «ВДНХ»","hour":8,"value":221.9,"dayTotal":2291.0}],
 "fleet":{"available":true,"candidateHours":43,"extraVehicleHours":102,"reserveHours":21,"reserveVehicleHours":79},
 "events":[{"kind":"event","name":"Т1","routes":[7],"note":"...","source":["https://..."]}],
 "recommendations":["Пик сети — 08:00: 23 613 посадок (9,6 % суток, прогноз).","Маршрут 26: усилить выпуск — 8:00 +7, ..."],
 "scenario":false,"computeMs":8.9}
```

- `weekAgo*` — **сопоставимый день**: ближайший прошлый день с тем же днём недели и тем же типом дня (праздники
  пропускаются), до 8 недель назад; `null`, если такого нет.
- `routes` отсортированы по посадкам за сутки. `reinforceHours` — часы усиления выпуска (есть только для
  01.11–31.12.2025; `fleet.available=false` вне этого периода).
- `hotStops` — 10 остановок с наибольшими посадками в час пика своего маршрута (оценка по доле остановки).
- `events` — действующие события (`event`) и режимы маршрутов (`regime`) со ссылками на источники.
- Резерв: `routes[].reserveVehicleHours`, `routes[].reserveHours` (`[{"hour":21,"pred":483,"nPlan":13.0,"norm":119.3,
  "need":6,"reserve":3}]`), `fleet.reserveHours`, `fleet.reserveVehicleHours`. В рекомендациях есть строки «можно
  сократить выпуск» и «Баланс выпуска за день».

## Приём потоковых данных и мониторинг

### POST /api/v1/ingest/validations

Тело — сырые валидации:
- `text/csv`: формат `train.csv`/`test.csv` (`;`, заголовок; нужны `tran_date_time`, `validation_result`, `ngpt_route`);
- `application/json`: `[{"tranDateTime":"2025-11-01 00:13:40","validationResult":1,"ngptRoute":"7 трамвай"}]`.

Нормализация: посадка = `validation_result == 1`, маршрут — число из `ngpt_route`, время — `tran_date_time`.
Ответ: `{"received":1000,"accepted":950,"rejected":50,"boardings":930,"cells":12}`.

### GET /api/v1/monitoring?date=2025-11-01

Факт из приёма против прогноза (для дат истории — против эталонного факта labels, это сверка приёма):

```json
{"date":"2025-10-31","forecastSource":"эталонный факт labels (сверка приёма)","lastHour":23,
 "hoursCovered":[20,21,22,23],
 "cells":[{"route":7,"hour":20,"actual":1210,"forecast":1212.0}],
 "actualTotal":20945,"forecastTotal":225645.0,"coveredActual":18228,"coveredForecast":18228.0,
 "wapeScore":1.0,"receivedTotal":23446,"boardingsTotal":21799}
```

`hoursCovered` — «принятые» часы: факт по сети не меньше 50 % прогноза. `wapeScore` считается только по ним, так
что незавершённый поток и единичные запоздавшие записи оценку не портят. 1.11.2025 00–01 ч не оцениваются:
в прогнозе на эти часы уже стоит факт (хвост `test.csv`). `boardingsTotal`/`receivedTotal` — по всему приёму,
по всем датам. Записи с датами вне 2025-01-01 … 2026-12-31 отклоняются (`rejected`). `actualTotal`/`forecastTotal` — за
весь день, `coveredActual`/`coveredForecast` — за принятые часы.

**Детектор смены режима.** Параметры `threshold` (порог отклонения, 0.05–0.9, по умолчанию 0.25) и `minHours`
(часов подряд, 1–12, по умолчанию 2). В ответе:

```json
"alerts":[{"route":7,"fromHour":9,"toHour":12,"hours":4,"actual":2583,"forecast":6630.0,"deviationPct":-61.0,
           "kind":"drop","message":"Маршрут 7: факт ниже прогноза на 61 % 4 ч подряд (09:00–13:00) — вероятно ремонт, ..."}],
"alertParams":{"threshold":0.25,"minHours":2,"minForecast":30.0}
```

Серия — подряд идущие «принятые» часы, где факт маршрута отклоняется от прогноза больше порога в одну сторону
(ячейки с прогнозом < 30 посадок не оцениваются). `drop` — вероятный ремонт, перекрытие, сход с линии; `surge` —
перераспределение пассажиров или массовое событие. Сигнал означает: внести режим в `regimes.json` и пересчитать прогноз.

### POST /api/v1/ingest/simulate

Симуляция потока валидаций на дату — для демонстрации детектора (реальных данных за прогнозный период нет).
Параметры: `date` (обязательно), `toHour` (по умолчанию 23), `anomalyRoute`, `anomalyFromHour`, `anomalyToHour`,
`anomalyMult` (по умолчанию 0.4), `seed`. Посадки = прогноз (для истории — факт) × (1 ± 5 % шума), в часах
аномалии маршрута — × `anomalyMult`. Ответ: `{"received":131826,"accepted":131826,"rejected":0,"boardings":131826,
"cells":113,"simulated":true}`.

### DELETE /api/v1/ingest

Сброс принятых данных.
